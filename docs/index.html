macOS menu bar · GitHub Actions

GitHub Actions, in your menu bar.

Watch the repos you ship. Pin Deploy to prod so it never drowns in someone else’s CI. Filter to your commits, PRs, and dispatches. RunBar uses the gh session already on your Mac.

  • macOS 14+
  • Free & open source
  • No tokens stored
Install from source Source on GitHub
build on your Mac 
git clone https://github.com/bryaneaton13/gh-actions-runbar.git
cd gh-actions-runbar
make install
open ~/Applications/RunBar.app
check / status

Live running and fail state

The bar shows a count while jobs are in progress and tints red after a watched failure, including pinned deploys that failed hours ago.

workflow / pin

Pins for Deploy to prod

Pinned workflows ignore actor and event filters, so the run that actually ships stays at the top of the panel.

filter / actor

Your runs, not the whole org

Limit the list to the commits, pull requests, and workflow_dispatch jobs you triggered.

Privacy

RunBar shells out to the GitHub CLI. It does not store a token or password. Settings live in ~/.config/runbar/config.json. It does not crawl your disk. Read the privacy notes.

You need gh

Install with brew install gh, then gh auth login. First launch shows a copy-able command if gh is missing or signed out. Getting started.
